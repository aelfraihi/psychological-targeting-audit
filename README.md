# Auditing ad delivery responsiveness to psychological traits

Code, aggregate data, and study materials for **An Experimental Framework
for Auditing Ad Delivery Responsiveness to Psychological Traits**
(ICWSM 2027).

The paper asks whether an advertising platform allocates impressions
differently depending on how an ad is framed relative to the personality
of the audience receiving it. Psychological traits are not exposed as
targeting categories and leave no external record that researchers can
use to classify users, so the audit first has to build trait-defined
audiences and then measure how the platform splits delivery between a
trait-aligned and a trait-misaligned creative competing under identical
conditions.
